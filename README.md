# TermZero

纯净、无广告的 HarmonyOS 原生 SSH 客户端。

## 特性

- 连接管理：保存主机配置，密码 / 私钥（PEM）两种认证
- 真正的终端：自研 VT 渲染引擎，支持 vim、top、htop 等全屏 TUI，256 色与真彩色
- 快捷键条：Esc、Tab、Ctrl+C、方向键直接送达，不用切换输入法找符号
- 终端尺寸自适应：屏幕变化自动调整行列，侧栏缩放即时生效
- 明暗双主题

## 我们不做的事

- 没有广告
- 没有内购
- 没有统计 SDK，没有埋点
- 不收集任何个人数据

## 隐私

TermZero 不联网上传任何用户数据。连接配置仅保存在本机应用沙箱内。详见 [隐私政策](PRIVACY.md)。
